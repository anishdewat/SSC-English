# SSC English Notes

Live site: https://anishdewat.github.io/SSC-English/

## Add notes
1. Open (or create) a folder named after the topic, using underscores: `Spellings/`, `Subject_Verb_Agreement/`
2. Upload the lecture as `01.html`, `02.html`, ... inside it (GitHub → Add file → Upload files).
3. Commit. The site rebuilds automatically in ~1 minute.
